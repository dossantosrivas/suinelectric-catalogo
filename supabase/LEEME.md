# Base de datos (Supabase)

- `estructura_actual.sql`: copia exacta de la estructura de la base real (tablas, funciones, reglas de acceso, permisos), sacada el 2026-10-05. Es la referencia de cómo está la base hoy.
- `01_…sql` a `15_…sql`: los guiones con los que se fue armando la base, en orden. Algunos cambios se hicieron después a mano en Supabase, por eso la referencia completa es `estructura_actual.sql`.

De aquí en adelante, cada cambio a la base se guarda como un archivo nuevo numerado (16_…, 17_…) para no perder el historial.
